# 🐄 Doodh Tracker

Gaay & Bhains ka doodh hisaab tracker — subah/shaam milk record with stats & charts.

## Features

- 🐄 **Janwar Manage** — Gaay aur Bhains add karo, naam/tag number ke saath
- 🥛 **Daily Entry** — Subah aur Shaam ka doodh (litre) separately record karo
- 📊 **Stats & Charts** — 7-day bar chart, Gaay vs Bhains pie chart, per-animal ranking
- 💾 **Local Storage** — Saara data browser mein save hota hai, koi backend nahi chahiye
- 📱 **Mobile First** — Phone pe perfectly chalta hai

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Zustand (state management)
- Custom SVG charts (no chart library needed)

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
